      Multiversion

      Translates older Java Edition clients to 26.3 inside the server. Tested joining: 1.21.11 and 26.1. Older versions are admitted but can't finish joining yet.

      Server culling Experimental

      Only sends players what they could see. Buried ores and chests are hidden from xray, and players and mobs behind walls from ESP. Covers 26.3 Java clients only.

      PatchBukkit

      Runs Bukkit, Spigot and Paper plugins. Needs Java 25 or newer. Drop jars into .
